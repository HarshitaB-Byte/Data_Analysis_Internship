## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles Dataset using Python and Pandas.

## Objectives
- Understand dataset structure and variables
- Analyze Movies vs TV Shows distribution
- Identify top content-producing countries
- Study content ratings and release trends
- Detect missing values and data quality issues
- Generate business insights through visualization

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
  
Visualizations Created
- Movies vs TV Shows Distribution
- Content Ratings Analysis
- Top Countries by Content Count
- Netflix Content Growth Over Time

## Dataset Information
- Dataset: Netflix Titles Dataset
- Rows: 8807
- Columns: 12
- Features include:
  - type
  - title
  - director
  - cast
  - country
  - release_year
  - rating
  - duration 

## Key Findings
- Movies represent the majority of Netflix content.
- United States and India contribute the highest number of titles.
- Netflix content additions peaked around 2019.
- TV-MA is the most common content rating.
- Several missing values were identified in director, cast, and country columns.
